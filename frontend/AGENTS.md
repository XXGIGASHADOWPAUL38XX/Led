This frontend uses React, Vite, TypeScript, and Tailwind CSS.

- Keep application components in the existing `src/components` structure.
- `src/main.tsx` mounts `src/app/page.tsx`; `src/app/globals.css` contains shared styles.
- Preserve the direct binary WebSocket connection to Python.
- Use `npm run dev`, `npm run build`, and `npm run start` (local build preview).
